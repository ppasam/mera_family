# Боевой поиск за 4 шага

Модуль ищет товары в вашей собственной сессии маркетплейса, поэтому нужен
установленный **Chrome** и **Python 3.12 или новее**.

## 1. Окружение

Один раз, в каталоге `raw/project`:

**Linux / macOS**

```bash
cd raw/project
python3 -m venv .venv
.venv/bin/pip install -e .
```

**Windows** (PowerShell)

```powershell
cd C:\mera_family\raw\project
Remove-Item -Recurse -Force .venv -ErrorAction SilentlyContinue
py -3.12 -m venv .venv
.venv\Scripts\pip install -e .
```

⚠️ На Windows папку `.venv` из архива нужно именно **удалить**, а не
переиспользовать: она собрана под Linux и там не работает — другой формат
исполняемых файлов и другая структура папок.

При установке Python обязательно отметьте галочку **«Add python.exe to PATH»**.

## 2. Запуск

**Linux / macOS**

```bash
.venv/bin/wishlist serve
```

**Windows**

```powershell
.venv\Scripts\wishlist serve
```

Сервер напечатает, с чем работает:

```
Интерфейс подбора: http://127.0.0.1:8765/
Список желаний:    …/raw/project/config/wishlist.yaml
Профиль браузера:  …/wishlist-buyer/chrome-profile
```

Запускать нужно **из каталога `raw/project`**: путь к списку желаний
относительный, из другого места модуль заведёт отдельный файл.

## 3. Поиск

Откройте **http://127.0.0.1:8765** и введите товар.

Что произойдёт: откроется окно Chrome, модуль найдёт предложения на витрине и
покажет 1–3 лучших по цене и сроку доставки — с объяснением, почему именно эти.

Поиск через строку разовый и список желаний не меняет. Сам список — в
`config/wishlist.yaml`; чтобы пройти его целиком:

```bash
.venv/bin/wishlist run            # Windows: .venv\Scripts\wishlist run
```

Окно Chrome **не закрывайте**: это рабочая сессия, она переиспользуется между
поисками. Первый поиск дольше остальных — браузер поднимается.

## 4. Вход в аккаунт — по желанию

Для поиска не нужен. Нужен, чтобы видеть цены с картой Ozon и класть товары в
корзину:

```bash
.venv/bin/wishlist login          # Windows: .venv\Scripts\wishlist login
```

Откроется окно, вход выполняете вы сами. Пароль и код из СМС модуль не видит и
не хранит. Дальше сессия живёт в его профиле браузера.

## Если что-то пошло не так

| Симптом | Причина и что делать |
|---|---|
| `wishlist: command not found` | окружение не установлено или команда запущена без пути: `.venv/bin/wishlist` (Windows: `.venv\Scripts\wishlist`) |
| Страница открылась, но поиск не идёт | смотрите окно терминала: там будет причина |
| «Ozon показал проверку» | решите капчу в открытом окне Chrome и повторите поиск — модуль её не обходит |
| «исчерпан лимит запросов за сессию» | защитный лимит: 18 переходов на прогон. Перезапустите сервер |
| Список желаний оказался не тот | сервер запущен из другого каталога — смотрите путь, который он печатает при старте |
| Chrome не открывается | не установлен системный Chrome: модуль запускает именно его, а не собственный браузер |
| «не удалось открыть браузер с профилем» | модуль уже запущен в другом окне — профиль браузера один, держать его может только один процесс |

## Что модуль не делает

Не оплачивает покупки — никогда. Не обходит капчу. Не хранит ваши пароли.
Кнопка покупки на странице пока только показывает сценарий: в корзину она ничего
не кладёт.
