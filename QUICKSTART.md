# Боевой поиск: как запускать

Модуль ищет товары в вашей собственной сессии маркетплейса, поэтому нужен
установленный **Chrome** и **Python 3.12 или новее**.

## 1. Окружение

Один раз, в каталоге `raw/project`:

**Linux / macOS**

```bash
cd raw/project
python3 -m venv .venv
.venv/bin/pip install -e .
```

**Windows** (PowerShell)

```powershell
cd C:\mera_family\raw\project
Remove-Item -Recurse -Force .venv -ErrorAction SilentlyContinue
py -3.12 -m venv .venv
.venv\Scripts\pip install -e .
```

⚠️ На Windows папку `.venv` из архива нужно именно **удалить**, а не
переиспользовать: она собрана под Linux и там не работает — другой формат
исполняемых файлов и другая структура папок.

При установке Python обязательно отметьте галочку **«Add python.exe to PATH»**.

## 2. Два способа искать

Способ выбирается тем, что вы запускаете. Оба работают в вашей сессии Ozon и
ничего не покупают.

### По списку желаний — `run`

Проходит все товары из `config/wishlist.yaml` подряд и по каждому показывает
1–3 лучших варианта.

```bash
.venv/bin/wishlist run                # Windows: .venv\Scripts\wishlist run
```

Между товарами модуль ждёт 45 секунд — это защита от блокировки, а не
медлительность. Список из трёх товаров займёт около полутора минут.

Результат печатается в терминале карточками: цена, скидка, срок доставки,
рейтинг, продавец и объяснение, почему вариант попал в подборку.

Список желаний правится руками — в редакторе или в Obsidian. Формат: одна
строка на товар либо развёрнутая запись с уточнениями; обязательное поле одно —
`query`, из остальных на отбор влияют `must_exclude`, `must_include` и
`max_price`. Все поля с пояснениями — в `config/wishlist.example.yaml`.

### Разовый поиск — `serve`

Поднимает страницу подбора в браузере: вводите товар, получаете те же 1–3
варианта, но с картинками и кнопкой выбора.

```bash
.venv/bin/wishlist serve              # Windows: .venv\Scripts\wishlist serve
```

Откройте адрес, который напечатает сервер — **http://127.0.0.1:8765**.

Поиск через строку **разовый**: список желаний он не меняет. Список при этом
виден на странице — клик по товару ищет его, крестик убирает из списка.

Кнопка **«Пройти весь список»** делает на странице то же, что `run` в терминале:
идёт по товарам подряд и показывает по каждому свои варианты. Паузу между
товарами видно отсчётом, обход можно остановить кнопкой.

Остановить сервер — Ctrl+C.

### Что важно для обоих

Запускать **из каталога `raw/project`**: путь к списку желаний относительный.

Окно Chrome, которое откроется, **не закрывайте** — это рабочая сессия, она
переиспользуется между поисками. Первый поиск дольше остальных: браузер
поднимается.

⚠️ **Не запускайте `run` и `serve` одновременно** — профиль браузера один, и
второй запуск честно скажет, что он занят.

## 3. Вход в аккаунт — по желанию

Для поиска не нужен. Нужен, чтобы видеть цены с картой Ozon и класть товары в
корзину:

```bash
.venv/bin/wishlist login          # Windows: .venv\Scripts\wishlist login
```

Откроется окно, вход выполняете вы сами. Пароль и код из СМС модуль не видит и
не хранит. Дальше сессия живёт в его профиле браузера.

## Если что-то пошло не так

| Симптом | Причина и что делать |
|---|---|
| `wishlist: command not found` | окружение не установлено или команда запущена без пути: `.venv/bin/wishlist` (Windows: `.venv\Scripts\wishlist`) |
| Страница открылась, но поиск не идёт | смотрите окно терминала: там будет причина |
| «Ozon показал проверку» | решите капчу в открытом окне Chrome и повторите поиск — модуль её не обходит |
| «исчерпан лимит запросов за сессию» | защитный лимит: 18 переходов на прогон. Перезапустите сервер |
| Список желаний оказался не тот | сервер запущен из другого каталога — смотрите путь, который он печатает при старте |
| Chrome не открывается | не установлен системный Chrome: модуль запускает именно его, а не собственный браузер |
| «не удалось открыть браузер с профилем» | модуль уже запущен в другом окне — профиль браузера один, держать его может только один процесс |

## Что модуль не делает

Не оплачивает покупки — никогда. Не обходит капчу. Не хранит ваши пароли.
Кнопка покупки на странице пока только показывает сценарий: в корзину она ничего
не кладёт.
